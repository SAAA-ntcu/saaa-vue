# SAAA Logo Web Kit

Files:

- `saaa-logo-horizontal.svg` — full horizontal master logo
- `saaa-logo-header.svg` — tighter crop for website headers/navbars
- `saaa-logo-icon.svg` — standalone full-color symbol
- `saaa-logo-monochrome.svg` — single-brand-color horizontal logo
- `favicon.svg` — simplified 64×64 browser favicon

Suggested use:

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<img src="/images/saaa-logo-header.svg" alt="縣市學生學習能力檢測">
```

Brand colors:
- Deep green `#5F7F6F`
- Soft green `#9CB89A`
- Warm cream `#FFFBE7`
- Gold `#F0C363`
- Dark blue-gray `#203B46`
